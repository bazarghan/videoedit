# Bundled Persian fonts

Unmodified regular TrueType fonts from their upstream releases. Open-source fonts include their upstream license in this directory; the proprietary IRAN Yekan font ships with a license notice instead.

- [Vazirmatn-Regular.ttf](https://github.com/rastikerdar/vazirmatn/releases/tag/v33.003) (v33.003)
- [Shabnam.ttf](https://github.com/rastikerdar/shabnam-font/releases/tag/v5.0.1) (v5.0.1)
- [Sahel.ttf](https://github.com/rastikerdar/sahel-font/releases/tag/v3.4.0) (v3.4.0)
- IRANYekanWebRegular.ttf (IRAN Yekan Web Regular, [fontiran.com](https://www.fontiran.com)); proprietary, see [IRANYekanWeb-LICENSE.txt](IRANYekanWeb-LICENSE.txt)

The browser and FFmpeg read these same files. Docker also installs them in Fontconfig for subtitle rendering.
